# 方法论摘要（可喂 Argon）

基于《钟意婚礼主持创作方法论》与《婚礼项目指令｜台词创作模块》提炼。目标风格：克制、真实、具体、有人情味、不油腻、有思考、有现场感，可有轻微幽默；徐岩式骨架（全场兼容、因果链）+ 赵轩宇式血肉（具体细节、现场感）。

## 最高原则

事实高于文采。不得编造未提供的事件、地点、时间、对话、心理、家庭经历、旅行、冲突。高级表达必须能向下追溯到档案事实。未说过的话不加引号。歧义标【待确认】。

## 扫描与关系

完整阅读新郎/新娘问卷、补充沟通、最终流程；禁止一题成稿。至少覆盖：性格、关系特点、见面与确认、结婚原因、改变、生活细节、时间线、异地/城市、重复行为、承诺兑现、求婚、父母、兴趣音乐、原话、婚姻观、日期场地天气装置、流程特殊安排、禁忌。

先判断「这两个人形成了怎样的关系」，再用 ≥3 条来自不同问题的独立事实交叉验证。证据不足 → 二次采访，不强行成稿。

## 素材价值

动作 > 评价；具体事件 > 抽象形容；重复行为 > 一次浪漫；可验证改变 > 静态标签；真实原话 > 主持人代写总结。

父母素材仅当「父母行动 → 新人性格 → 伴侣选择」链条成立时才可作开场主线。

## 母题与现场

一篇开场一个核心母题、一个主要比喻系统（最多一个辅助意象）。常见母题：时间、地理迁徙、真实物件、人物成长、家庭传承、关系真相、婚礼现场。现场天气/装置只做入口，必须连接真实经历；不为高级感强行山海星辰命运。

## 开场与流程分配

默认路径：入口 → 真实事实 → 多条事实形成关系 → 提炼意义 → 回到今天。大型晚宴须让不熟的长辈听懂「他们是谁、为何值得祝福」。

开场建立关系，流程逐渐补全人物。按环节分配：入场补侧面、誓言/戒指短接承诺、父母仅链条成立时展开、手捧花克制、退场收束。不要把所有好料塞进开场。

## 语言与审计

婚礼是说出来的：短句、口语、具体。高级表达稀缺。情绪：事实 → 感受 → 轻点意义。删连续排比、堆砌四字词、公众号腔、无信息感叹。

成稿前查：编造/强行因果/代猜心理/姓名日期地点/假引语/虚构场面/是否只用一条素材/是否双人问卷都用到/是否预支后续环节素材。最终标准：新人觉得「说的是我们」。

## 与诊断的关系

完整系统含七项诊断 + 三方向（不同叙事发动机）。**钟意默认写稿约定**：对外可跳过三方向展示，内部仍完成扫描与关系结论，**直出约 2 分钟开场**；用户明确要求诊断时再输出七项+三方向。
