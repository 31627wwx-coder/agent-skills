## A. 钟意自有开场（001–004）

### 001｜雨水与生长｜开场
- 标签：现场天气｜场布意象｜植物生长｜校园长恋｜细水长流｜人物改变｜宾客共同体
- 结构路径：现场雨景 → 植物生长 → 关系原话 → 校园关系 → 「互相补课」反转 → 宾客成为滋养 → 入场
- 学习点：
  1. 现场元素须与新人原话/关系事实连接，不是装饰。
  2. 单一意象系统贯穿雨、植物、关系、宾客。
  3. 用可回溯事实的反转写人物改变。
  4. 把宾客从旁观者写进关系网络。
  5. 克制现场意象，不把天气强行解释成吉兆。
- 隐私边界：无额外禁用标记。

### 002｜真实物件与尊重｜开场
- 标签：真实物件｜尊重与理解｜彼此改变｜轻幽默｜克制不煽情
- 结构路径：婚礼期待 → 自然关系 → 真实小物件 → 尊重爱好→尊重人 → 双向改变 → 轻幽默回扣 → 入场
- 学习点：
  1. 用真实小物件进入关系，不先讲抽象爱情观。
  2. 意义从事实中长出（尊重爱好 → 尊重人）。
  3. 双向写人物变化。
  4. 轻幽默释放后回到关系结论。
  5. 不用宏大叙事证明「爱情伟大」，只见证两个具体的人。
- 隐私边界：【理解可用｜现场禁用】部分相识/职场背景新人明确不愿公开——他场同理：同行在场的敏感经历不开口播。

### 003｜人到了 / 认真的每周见面｜开场
- 标签：性格反差｜互相影响｜异地每周见｜同城收束｜互相欣赏｜宾客共同体｜松弛
- 结构路径：宾客到场 → 性格反差（做事习惯对打）→ 互相影响 → 每周见面（普通但认真）→ 同城 → 互相欣赏 → 幸福理解 → 热闹轻松见证人
- 学习点：
  1. 用宾客构成作入口，把现场人写进叙事。
  2. 性格反差用具体做事习惯，不写空标签。
  3. 「认真」靠具体动作（留路、留时间），不靠煽情。
  4. 欣赏点用双方眼里对方的具体词；幸福理解放在事实之后轻点。
  5. 收束回今晚气氛与见证人，不抢后续父母/问誓戏。
- 隐私边界：父母发言边界若为「代致辞/不发言」，开场可不展开。

### 004｜日久见人心 / 小事攒成大事｜开场｜常用结构模板
- 标签：宾客共同体｜细水长流｜日久生情｜新人原话｜小事确认｜人物改变｜三开心｜常用模板
- 结构路径：宾客与「三个开心」→ 无轰轰烈烈 + 性格侧面 → 「不是一眼定终身」→ 双方原话对打 → 小事确认感情 → 双向改变 → 决定=种种小事 → 今天大事=无数小事攒出 → 见证人
- 学习点：
  1. 把现场期待（如「三个开心」）嵌进开场，顺手接互动需求，不另立互动段。
  2. 性格侧面后立刻否定「第一眼轰轰烈烈」，用「每一次相处」把时间写具体。
  3. 保留双方原话对打，再一句收束「词不一样、说的是同一件事」。
  4. 同一意象三层递进（舒服关系 / 决定 / 今天大事），不另开比喻系统。
  5. 收束回见证人与往后日子；问卷要求少讲故事时，用关系质感代替故事串讲。
- 隐私边界：结构可复用；姓名/原话/桌数须按本场改写。
- 模板可用：是。

## C. 选用指引（写稿时）

1. 先定本场关系结论与母题，再在 A 中找相近结构路径；需要骨架/血肉技巧时查 B。
2. 004 可作为「日久生情 / 小事确认 / 少讲轰轰烈烈故事」类场的默认结构模板。
3. 任何匹配都只迁移**路径与手法**，不迁移原话、物件名、城市细节与成句。
