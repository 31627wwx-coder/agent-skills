# 电脑大保健（windows-pc-health-check）

> Agent Skills 兼容包：文件夹名与 frontmatter `name` 为 `windows-pc-health-check`；正文以中文流程为主。

对用户指定的 Windows 电脑做一轮「扫描 → 汇报批准 → 执行 → 复查」。默认**只汇报、不擅自删/升/关**；用户勾选后才动手。主机与笔记本通用；用当前对话指定的机器，未指定则用用户最新消息所在电脑。

面向普通人日常维护：清可再生垃圾、收敛开机噪音、装安全相关更新、确认安全中心与磁盘健康、把大文件默认路径指到大容量盘。不做「注册表神优化」、不乱 debloat、不关电源策略（除非用户点名）。

## 硬约束（始终遵守）
- 不代付；不擅自卸载 Steam/游戏（除非用户点名）。
- 不关休眠/电源/睡眠策略，除非用户另说。
- 不删照片库（含 iCloud 同步库）内容；删前必须确认。不要开「优化 iPhone/iCloud 存储」一类会清本地原图的选项。
- 代理/翻墙：优先保留用户**当前在用**的客户端；卸旧客户端前先备份配置并获批。日常推荐「规则 + 系统代理」；**虚拟网卡(TUN)默认保持关**（易把网盘/同步流量送出国烧流量），除非用户明确要开。
- 开发工具（Node.js、Python 等）：若用户还在用相关 CLI，默认保留，卸前先问；多版本并存时测哪个可用，建议留一个。
- Windows 更新：**厂商固件默认不升**；大型功能更新默认不升。Defender 平台/定义与明确有益的外设驱动可建议；装前获批。装完若需重启，问过再重启，**禁止自动重启**。

## 流程

### 0. 锁定目标机
确认目标电脑已连接、可执行本机命令。无法连接则停止并说明。

### 1. 存储体检（只读）
报告：各盘总容量/剩余；用户目录与常见大户（Downloads、Videos、AppData、临时目录、安装包缓存、重复下载、明显废弃软件目录）。
分类建议（每项带路径与大约体积）：
- **安全可清（可再生）**：`%TEMP%`、回收站、Windows Update 下载缓存、winget/安装包缓存、浏览器缓存、缩略图缓存、Delivery Optimization 等——清了系统会重建。
- **建议确认后清**：重复媒体、旧项目残留、已卸软件的配置目录、旧版通讯软件残留安装目录。
- **默认不动**：桌面点名保留项、照片库、游戏库、正在用的工程/素材盘、用户明确要留的目录。
优先用系统自带手段（Storage Sense、`cleanmgr`、DISM 组件清理等）处理安全可清项；获批后再动手动删。交付清单后等待勾选。

### 2. 软件冗余体检（只读）
列出可卸候选：停更的旧代理客户端、重复工具、明确废弃的助手/面板、用户已声明不用的远程桌面（如向日葵、ToDesk/TwoDesk）等。
远程控制类：若用户不用，优先建议**关自启**；确认不用后再建议清残余配置或卸载。
多版本运行时（Python 等）：测可用性，建议留一个卸其余，获批后再卸。

### 3. 软件更新体检（只读）
用 winget（及必要的 msstore）列出可升级项，分成：
- **建议小版本/安全更新**
- **通讯刚需**（微信/飞书/腾讯会议等，若本机有）
- **跨大版本/可选**（默认先不动）
- **明确排除**（用户曾拒绝过的包，记在当次汇报里）
只汇报；获批名单后再升级。升级易把开机项写回，第 4 步之后再核对一遍自启。

### 4. 开机启动项体检（只读 → 获批后改）
汇总 HKCU/HKLM `Run`、`StartupApproved`、Startup 文件夹、相关计划任务与用户能感知的自启服务。
标注：实际会启动 / 已登记但已关 / 幽灵残留。
**改之前**：导出当前 Run / StartupApproved（或抄一份键名清单）作简易备份，便于误关后恢复。
常见建议关闭（有则提出，获批再关）：AI 助手后台、音乐客户端后台、办公套件强行自启、网盘更新器、不用的远程控制、PDF 工具自启等。
保留建议：当前代理客户端、用户明确要的同步/壁纸工具。
关自启：去掉对应用户 Run 值，StartupApproved 置禁用；需要「彻底减噪音」时可移除已禁用的幽灵 Run 键（获批）。HKLM 需提权。服务类改为 Manual/Disabled 须获批。

### 5. Windows 更新研判（只读 → 获批后装）
COM/系统更新搜索待装项，按类建议：
- **建议**：Defender 平台/安全相关、明确有益的外设驱动。
- **可不急**：杂项驱动。
- **默认跳过**：厂商 Firmware/固件、大型功能更新。
获批后只装批准类别；装完复扫，报告是否仍 pending、是否需要重启（不自动重启）。

### 6. 安全与磁盘健康（只读汇报）
每轮扫描都看一眼，默认只汇报：
- Windows 安全中心 / Defender：是否有**未处理威胁**、近期检测摘要。
- 磁盘健康：各盘剩余空间；物理盘 SMART/健康状态（只读）。异常则标红建议用户备份或换盘，不擅自跑修复。

### 7. 默认路径体检（有大容量盘时提出）
若除系统盘外还有大容量盘：检查「视频 / 下载 / 剪辑工程与导出」是否仍堆在系统盘。
建议（获批再改）：把 Windows「视频」等用户文件夹、剪映/录屏/常见剪辑软件的默认保存与导出，指到大容量盘上的素材或工程目录（没有则先建清晰结构再改）。**优先改默认路径，不擅自搬移已有大文件。**

### 8. 执行与复查
按批准项执行。清「已卸软件残余配置」仅限用户点名确认不用的（如向日葵配置）；通讯软件旧目录默认不动。
若用户要求重启：执行重启，待用户确认回来后复查：
- 代理是否自启、系统代理是否正常；国内站与需代理站点抽测。
- 已关开机项是否被软件写回；磁盘与关键服务是否异常；近半小时系统错误日志有无新问题。

### 9. 交付
用简短中文总结：做了什么、跳过了什么、遗留（旧目录/配置残留/可能被写回的自启）、可选下次项。需要固化偏好时写入 memory。

## 推荐加项（扫描时提出，勿默认执行）
- 浏览器扩展清单：Chrome/Edge 已装扩展名与启用状态；标出明显无用或长期不用的，等用户勾选再关/卸。
- 开机项二次收敛：把「登记但已关」的幽灵键彻底移除减噪音。
- 更深磁盘清理：旧 Windows 更新残留、WinSxS 组件清理（`DISM`，耗时长，获批且插电时再做）。
- 电源：仅在用户要求时检查睡眠/休眠/盖盖动作。
- 远程控制：不用则关自启 → 清配置 → 再考虑卸载。
